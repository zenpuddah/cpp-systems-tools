# A1–A3 execution plan

1. `include/tcp_kv/protocol.hpp`, `src/protocol.cpp`: pure LF-frame parser and bounded `Store`; test ASCII/grammar/length precedence and 1,024-key replacement.
2. `include/tcp_kv/{fd,connection}.hpp`, `src/connection.cpp`: move-only FD, injected transport, retained input/output offsets, bounded fair turns and monotonic draining; deterministic short-write/EINTR/EAGAIN/overflow/EOF tests in `tests/unit.cpp`.
3. `src/main.cpp`: one owning thread, explicit nonblocking/CLOEXEC socket setup, IPv4 loopback poll reactor, bounded accepts and signal shutdown; `tests/integration.py` uses ephemeral ports, READY, deadlines and unconditional cleanup.
4. `CMakeLists.txt`: `tcp-kv`, `tcp-kv-unit`, unit and integration CTest entries; assertions independent of NDEBUG. `README.md` and `docs/architecture.md`: usage, exact recovery and limits, state diagram. `progress.md`: actual verification only.

Protocol decisions: max frame length (including LF) precedes invalid bytes, then command, then syntax, key length, value length. The verb token must be exactly uppercase SET/GET/DEL; a known verb alone is a syntax error. GET/DEL reject extra spaces/arguments. SET uses one separator before key and one before value; all remaining value spaces are preserved. Empty fields are syntax errors. Unterminated EOF tail receives `ERROR incomplete_line`; an overlong unterminated line receives one `ERROR line_too_long`, discards until LF, then recovers. Buffer overflow closes without reply. EOF processes all complete buffered frames before tail error and output drain. Normal EOF drain and global signal shutdown each have an absolute two-second steady-clock deadline; global shutdown stops intake and discards unprocessed requests, draining already queued replies only.
